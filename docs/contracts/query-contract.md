# Query Contract

런타임 봇이 호출할 수 있는 DB 함수의 **전체 목록**이다. 이 목록에 없는 데이터 접근은 금지된다.

## 규칙

1. 모든 함수는 읽기 전용
2. 모든 함수는 `location` 파라미터를 받는다 (전체 조회 시 null)
3. 금액 반환 단위와 세금·팁 포함 여부를 함수마다 명시한다
4. 함수를 추가할 때 이 문서와 `runtime/router/`를 **동시에** 갱신한다 (`add-query-function` 스킬이 강제)
5. 새 함수는 상상해서 만들지 않는다. `output/unanswered.jsonl`에 쌓인 실제 질문을 근거로 추가한다

## 함수 목록

> 상태: 미구현 — M1 7단계에서 작성한다.

| 함수 | 용도 | 상태 |
|---|---|---|
| `get_sales_summary` | 기간·매장별 Net Sales, 주문 수, 객단가 | 미구현 |
| `get_sales_by_hour` | 시간대별 매출·주문 수 | 미구현 |
| `get_top_items` | 기간·매장별 판매 상위 품목 | 미구현 |
| `get_item_sales` | 특정 품목의 기간별 판매 추이 | 미구현 |
| `get_sync_status` | 최근 동기화 이력과 검증 결과 | 미구현 |

## 명세 서식

함수를 구현할 때마다 아래 형식으로 이 문서에 추가한다.

```
### 함수명

용도       한 줄 설명 (LLM이 이 설명을 보고 함수를 고른다)
파라미터   이름 · 타입 · 필수 여부 · 기본값
반환       필드명 · 타입 · 단위 · 세금/팁 포함 여부
주의       알아야 할 제약이나 함정
```
