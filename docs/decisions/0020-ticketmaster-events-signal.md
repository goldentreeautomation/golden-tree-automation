# 0020. Regina 시장 수요 예상에 지역행사(Ticketmaster) 신호 추가

- 날짜: 2026-09-09
- 상태: 채택

## 맥락

`0007`(Regina 시장 수요 예상) 설계 당시부터 "지역행사" 신호는 스펙(가중치 0~+20)만 있고 구현이 안 된 상태였다 — 신뢰할 만한 무료 데이터 소스를 못 찾아서(`market_demand_snapshots.event_impact` 항상 0, `source_status.unavailable`에 계속 남아있었음). 오너가 실제 운영 중 관찰한 사례를 근거로 다시 요청: "저번주말에 라이더스 홈경기 위니펙전 해서 사람이 많았다."

이번에 다시 조사(교통 신호도 같이 조사, 별도 판단은 본문 하단)한 결과, 여러 후보 중 Ticketmaster Discovery API가 유일하게 즉시 쓸 수 있는 무료 옵션으로 확인됨.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| City of Regina 오픈데이터 포털 | 리자이나 전용, 행사·도로 데이터 다 있을 가능성 | 이번에도 접속 차단(DNS 실패/403) — 재조사 때마다 반복됨 |
| Eventbrite API | 한때 공개 행사 검색 지원 | 공개 검색 엔드포인트 폐지됨(자기 조직 행사 관리용으로 축소) — 못 씀 |
| reginaevents.ca(동네 커뮤니티 캘린더) | 동네 소규모 행사까지 폭넓게 커버 | API/피드 없음, 접속도 막힘 — 스크래핑밖에 없는데 이번엔 보류 |
| **Ticketmaster Discovery API** | 무료(하루 5,000건), 실제 라이더스 홈경기(Mosaic Stadium)·Regina Pats(Brandt Centre) 다 잡힘, 안정적으로 접속됨 | 티켓 판매 행사만 잡힘 — 동네 축제·파머스마켓은 안 잡힘(알려진 한계) |

## 결정

**Ticketmaster Discovery API 채택.** `sync/market-demand`가 매시간 15분 실행될 때 리자이나(`city=Regina`) 행사 목록을 가져와(5분 캐시로 같은 실행 안에서 중복 호출 방지) 오늘 날짜에 해당하는 행사를 찾고, 장소 기준으로 가중치를 준다:

| 장소/행사 | 가중치 |
|---|---|
| Mosaic Stadium + "Roughriders" 포함 (라이더스 홈경기) | +20 (최대치) |
| Mosaic Stadium 기타 행사(콘서트 등) | +15 |
| Brandt Centre(Regina Pats 하키 등) | +8 |
| 그 외 티켓 행사 | +4 |

같은 날 여러 행사가 있으면 최댓값만 쓴다(합산하지 않음 — 중복·과대평가 방지). 리자이나 전체 단위 신호라 두 매장에 동일하게 적용한다(매장별 거리 가중치는 지금 안 함 — 필요해지면 추후 조정).

`market_demand_features`의 `nearby_event_count`/`weighted_event_score`/`events_confirmed`(스키마상 예전부터 있었으나 항상 0/false로 채워지던 컬럼)를 실제 값으로 채우기 시작.

### 교통/도로 신호는 이번엔 보류

서스캐처원 511(Highway Hotline)은 조사해봤으나 **고속도로 전용**(시내 교통과 무관)이고, 앨버타와 달리 공개 API 문서를 못 찾음. 리자이나 시내 교통이 카페/스시집 수요에 미치는 영향은 날씨·행사·요일보다 간접적일 것으로 판단해, 이번엔 추가하지 않고 우선순위를 낮춰 보류한다.

## 근거

- 오너가 직접 겪은 사례(라이더스 홈경기)로 신호의 실제 가치가 검증됨 — 추상적 스펙이 아니라 구체적 관찰에서 시작한 요청이라 가중치를 그 사례에 맞춰 가장 높게 설계함
- 무료·안정 접속이 최우선 기준 — City of Regina 포털은 이번이 두 번째 접속 실패라, 앞으로도 자동화 소스로 신뢰하기 어렵다고 판단
- 최댓값만 반영(합산 안 함): 스펙 상한(+20)을 지키면서, "행사가 여러 개면 무조건 더 붐빈다"는 단순 가정을 피함 — 근거 없는 정밀도보다 보수적인 추정을 선택(레시피 원가율 등 다른 기능에서도 일관되게 써온 원칙)

## 결과 (사후 기록)

`market-demand` v8 배포, 실행 확인(오늘은 리자이나에 행사가 없어 `event_impact=0`으로 정상 계산됨 — API 연결 자체는 정상). `source_status`에서 `events`가 `unavailable`에서 `ok`로 이동. `model_version`을 `rule-v1`→`rule-v2`로 올려 이 변경 전후 스냅샷을 구분 가능하게 함.
