# 0007. Regina 시장 수요 예상 (Market Demand Forecast)

- 날짜: 2026-08-25
- 상태: 채택

## 맥락

오너 요청: 대시보드가 지금까지 매출(지난 실적)에만 포커스가 있었는데, "오늘/이번 기간에 얼마나 바쁠지" 미리 가늠할 수 있는 예상 기능이 필요하다. 실제 방문객 수를 아는 방법은 없으므로(POS 트래커 없음), 확보 가능한 시장 신호(과거 같은 요일 실적, 날씨, 캘린더 등)를 조합한 "추정치"로 만든다.

오너가 화면 배치도 함께 지정: 기존 매출 위젯(주간 네비게이션 포함)은 그대로 두되 오른쪽으로 옮기고, 왼쪽(주력 위치)에 새 시장 수요 예상 패널을 넣는다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 처음부터 ML/회귀 모델 | 정교함 | 학습 데이터(실제 방문객·주문 실적) 절대량 부족 — 8주/200건 기준 미달, 과적합 위험 |
| 규칙 기반 점수(rule-based) + 학습 인프라만 먼저 구축 | 지금 바로 설명 가능한 값 제공, 데이터 쌓이면 나중에 회귀로 전환 가능 | 초기 정확도는 낮음 — 신뢰도(confidence)로 명시 |
| 유료 이벤트/트래픽 API 연동 | 신호 다양화 | 예산 승인(G2) 필요, 무료 대안 우선 조사가 먼저 |

## 결정

규칙 기반 점수 산정(base 50 ± 신호별 가중치)으로 v1을 만들고, 학습(회귀)에 필요한 원자료 축적 인프라(`market_demand_snapshots/features/outcomes` 3개 테이블)만 함께 만들어 둔다. 회귀 모델 전환은 실적이 충분히 쌓인 뒤(≥8주 또는 ≥200건) 별도 작업으로 미룬다.

구현 신호(v1):
- 과거 실적: 같은 매장·같은 시간대(오전/오후/저녁)·같은 요일 8주 평균 대비 편차 (`market_demand_baseline`, `market_demand_dow_profile`)
- 날씨: Open-Meteo(무료, 키 불필요) 기온·강수확률·적설·풍속
- 캘린더: 주말/SK 공휴일/디저트·카페 특수일(발렌타인데이 등)

미구현(항상 0, `source_status.unavailable`로 명시):
- 지역 행사 — 신뢰할 만한 무료 피드를 못 찾음 (City of Regina 오픈데이터 WebFetch 시도 DNS 실패)
- 검색 관심도 — GSC는 이 프로젝트 범위 밖 (0005 결정, 코덱스 사이드 프로젝트 소관)
- 도로/교통/대기질 — 아직 미조사

화면: 대시보드 왼쪽(주력) = 시장 수요 예상 패널(오전/오후/저녁 점수, 현재 시간대 강조, 주요 원인 리스트, 신뢰도, 어제 대비 변화, 마지막 갱신 시각, "실제 방문객 수 아님" 고지). 오른쪽(보조 위젯) = 기존 매출 카드 + 주간 네비게이션(그대로 유지).

동기화 주기: 매시간 15분(America/Regina, pg_cron `market-demand-hourly`). Square 매출 동기화도 이 기능이 최신 실적을 반영하도록 일 1회 → 매시간(`square-hourly-sync`)으로 변경, 48시간 고정 lookback으로 재작성(누적 밀림 방지).

## 근거

- 오너가 "정교한 예측"이 아니라 "미리 감 잡기"를 원했고, 스스로도 학습 모델의 데이터 요구량을 이해하고 있어(8주/200건 기준을 직접 제시) 규칙 기반 v1 + 인프라 선구축이 기대치와 일치.
- 무료·키 불필요·안정적인 소스(Open-Meteo, 우리 자체 Square 데이터)만 우선 사용 — 예산 승인 없이(G2 이전) 바로 배포 가능.
- 신뢰도(confidence) 필드를 신호 충분성에 연동해, 데이터가 부족한 신규 매장·기간에는 낮은 신뢰도로 표시되게 해 "가짜 정밀함"을 피함.

## 결과 (사후 기록)

배포 직후 실제 스냅샷 확인: CozyHaus 저녁 76/busy("화요일의 평소 수요가 높음", "야외 활동에 적합한 기온"), Bon Sushi 오전 77/busy 등 — 이유가 사람이 이해할 수 있는 문장으로 나옴. 대시보드 API(`dashboard-api` v9)·프론트(`dashboard` v10) 양쪽에서 정상 동작 확인.

향후: 지역 행사 무료 피드 재조사, `market_demand_outcomes`에 실적 8주 이상 쌓이면 Ridge/선형 회귀 주간 재학습 파이프라인 구축(챔피언/챌린저 비교, 성능 개선 시에만 교체, 자동 롤백).
